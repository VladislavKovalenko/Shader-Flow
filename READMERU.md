# Shader Flow — Плагин для Figma

[English Version](README.md)

Мощный плагин для Figma, предназначенный для создания, редактирования, композитинга и применения GLSL-шейдеров прямо на холсте. Генерируйте текстуры с нуля, обрабатывайте изображения цепочками эффектов, создавайте векторные и процедурные маски, применяйте глобальную Master Mask и экспортируйте результат обратно в Figma.

---

## Установка

https://youtu.be/F66oGiZPAd4

> Для установки плагинов разработчика требуется **десктопное приложение Figma**.

1. Нажмите правой кнопкой мыши на холсте.
2. Выберите **Plugins → Development → Import plugin from manifest**.
3. В открывшемся файловом менеджере найдите папку с исходным кодом плагина и выберите файл `manifest.json`.
4. Запустите плагин: он появится в **Plugins → Development → Shader Flow**. Нажмите на него для запуска.

## 🚀 Быстрый старт

[https://www.youtube.com/watch?v=7kSqcCyCGWI&t=35s](https://youtu.be/7kSqcCyCGWI)

1. Запустите **Shader Flow**.
2. Выберите **фрейм** (Frame) на холсте. Пропустите этот шаг, если работаете с отдельным изображением.
3. Выберите **слой с изображением** внутри фрейма.
4. Перейдите во вкладку **Library**.
5. Дважды нажмите на пресет или нажмите правой кнопкой мыши и выберите **Add as new layer**.
6. Перейдите во вкладку **Shader** и настройте параметры добавленного шейдера.
7. При необходимости добавьте маску для слоя или настройте глобальную **Master Mask**.
8. Примените результат:
   - **Add on top** — создает новое изображение поверх существующих заливок.
   - **Replace** — заменяет текущую заливку выбранного слоя с изображением.

## 1. Вкладка Shader — редактор и предпросмотр

<img width="800" height="580" alt="Снимок экрана 2026-08-18 114855" src="https://github.com/user-attachments/assets/a7b60188-245a-4542-b037-1863bd4500fd" />

> Основное рабочее пространство. Здесь вы пишете код, настраиваете параметры, управляете слоями и масками и видите результат в реальном времени.

### Пошаговое руководство

1. **Выберите слой в Figma.**  
   Если слой содержит изображение, плагин автоматически использует его в качестве текстуры для шейдера.

2. **Параметры** (левая панель).  
   Плагин сканирует GLSL-код и автоматически создает элементы управления для всех поддерживаемых `uniform`-переменных:

   - `float` / `int` — ползунки с автоматически определенными диапазонами.
   - `vec3`, в имени которого содержится `Color`, `color`, `Col` или `col`, — выбор цвета с HEX-вводом.
   - `bool` — переключатели.
   - `vec2` и другие числовые векторы — числовые поля ввода.
   - Изменения мгновенно отображаются в окне предпросмотра.

3. **Слои шейдера** (сворачиваемая панель слева).  
   Стек слоев используется для комбинирования генераторов и эффектов:

   - Нажмите `+`, чтобы открыть визуальный браузер пресетов и добавить слой.
   - **Generate** — создает изображение с нуля: градиенты, шум, огонь, плазму и другие эффекты.
   - **Effect** — обрабатывает результат предыдущего слоя: blur, bloom, хроматическая аберрация и другие эффекты.
   - Дважды нажмите на название слоя, чтобы переименовать его.
   - Нажмите `Enter`, чтобы подтвердить новое имя.
   - Нажмите `Escape`, чтобы отменить переименование.
   - Перетаскивайте слои мышью, чтобы изменить их порядок.
   - Верхний слой в списке рендерится последним.
   - У каждого слоя есть кнопка маски. Нажмите ее, чтобы открыть **Редактор стека масок**.

4. **Master Mask** (нижняя панель).  
   Master Mask — это глобальная маска, применяемая после композитинга всех слоев. Она влияет на итоговый результат, а не на отдельный слой.

   Master Mask используется для:

   - Виньетирования.
   - Кадрирования финального результата.
   - Создания рамок и композиционных границ.
   - Закругления или изменения формы итогового изображения.
   - Глобального затемнения и эффектов по краям.

5. **Редактор кода** (в центре).  
   Редактор кода GLSL с нумерацией строк. Пишите свой код или редактируйте загруженный пресет.

   Встроенные переменные, доступные без объявления:

   - `iResolution` — размер холста.
   - `iTime` — время анимации в секундах.
   - `iMouse` — позиция курсора в диапазоне `0..1`.
   - `uTexture` / `uHasTexture` — входная текстура и флаг ее наличия.

   Разделитель между редактором кода и окном предпросмотра можно перетаскивать по горизонтали, чтобы перераспределить рабочее пространство.

6. **Предпросмотр** (правая панель).  
   Интерактивный WebGL-предпросмотр на прозрачном фоне с шахматной сеткой.

   Элементы управления предпросмотром:

   - `⏸` — запуск или пауза анимации.
   - `↺` — сброс времени анимации на ноль.
   - `⇅` — отражение предпросмотра по вертикали.
   - `⇆` — отражение предпросмотра по горизонтали.

   Отражение предпросмотра используется только для просмотра и не влияет на экспортируемый результат.

7. **Панель ошибок** (Error Bar).  
   Ошибки компиляции GLSL отображаются под редактором. Используйте кнопку **Copy**, чтобы скопировать полное сообщение об ошибке в буфер обмена.

8. **Показать / скрыть редактор кода**.  
   Нажмите `</> Code` на нижней панели, чтобы скрыть редактор кода. Это удобно, если вы хотите работать только с параметрами и предпросмотром.

9. **Экспорт на холст** (нижняя панель):

   - **Replace** — заменяет содержимое выбранного слоя результатом рендеринга.
   - **Add on top** — создает новое изображение поверх выбранного слоя.
   - **Master Mask** — открывает редактор глобальной маски.
   - `</> Code` — показывает или скрывает редактор кода.

---

### Умные uniform-переменные

Shader Flow автоматически определяет диапазоны ползунков по именам `uniform`-переменных. Это упрощает работу с пресетами и не требует добавления метаданных в код шейдера.

| Имя переменной | Автоматически определяемый диапазон |
|:---|:---|
| `uAngle`, `uRotation` | `0..360` |
| `uCount`, `uTiles` | `1..100` |
| `uSpeed`, `uFrequency` | `0..5` |
| `uOpacity`, `uMix` | `0..1` |
| `uOffset`, `uShift` | `-1..1` |

Вы можете переопределить автоматический диапазон с помощью inline-комментария:

```glsl
uniform float uAngle; // @range -45 45
```

### Автоматический выбор цвета

Любая `uniform`-переменная типа `vec3`, имя которой содержит `Color`, `color`, `Col` или `col`, автоматически получает палитру выбора цвета с возможностью ввода HEX-кода.

```glsl
uniform vec3 uGlowColor;
uniform vec3 uAccentCol;
uniform vec3 uColorDeep;
```

## 2. Вкладка Library — библиотека шейдеров

<img width="800" height="580" alt="Снимок экрана 2026-08-18 120056" src="https://github.com/user-attachments/assets/2944e489-25ad-4efc-ab09-4ae7d4c6dab5" />

> Визуальное хранилище готовых шейдеров. Пресеты отображаются в виде карточек с живыми WebGL-миниатюрами.

### Что здесь находится

- **Basic Library** — встроенные пресеты, поставляемые с плагином:
  - 🌊 **Quantum Field** — гидродинамическое доменное искажение с каустиками.
  - 🌈 **Gradient Waves** — анимированные волнистые линии.
  - 🔥 **Fire** — сложный процедурный огонь с системой искр на основе частиц.
  - 🟣 **Plasma Storm** — объемная плазма с молниями Вороного.
  - 🌌 **Chromatic Aberration** — смещение цветов по краям.
  - 💧 **Glass / Ripple** — искажения стекла и ряби.
  - 🌫 **Gaussian Blur** — размытие по Гауссу.
  - ✨ **Bloom** — свечение для ярких областей.
  - ✏️ **Custom Generate** — шаблон для создания генератора с нуля.
  - ✏️ **Custom Effect** — шаблон для создания эффекта обработки изображений.

- **User Library** — ваши собственные шейдеры и цепочки.

### Иконки файлов

Файлы в библиотеке обозначаются цветными иконками в зависимости от их типа:

| Иконка | Тип файла | Описание |
|:---:|:---|:---|
| ◆ | `.sfshader` | Одиночный шейдер с кодом, параметрами и масками |
| ⛓ | `.sfchain` | Полная цепочка слоев с масками и настройками рендера |
| ≡ | `.txt` | Исходный файл GLSL |

### Как использовать

1. Просматривайте пресеты в визуальной сетке из двух колонок.
2. Наведите курсор на карточку, чтобы увидеть ее интерактивное состояние.
3. Дважды нажмите на файл `.txt` или `.sfshader`, чтобы добавить его в качестве нового слоя.
4. Также можно нажать правой кнопкой мыши на файл `.txt` или `.sfshader` и выбрать **Add as new layer**.
5. Нажмите правой кнопкой мыши на файл `.sfchain` и выберите **Load Chain**.
6. Если выбранный пресет является эффектом (**Effect**), убедитесь, что под ним в цепочке находится слой с изображением или генератор.
7. Отредактируйте параметры и примените результат к холсту.

### Пользовательская библиотека

Чтобы использовать собственную библиотеку шейдеров, откройте **Settings → Shader Library** и выберите папку, содержащую файлы `.txt`, `.sfshader` или `.sfchain`.

Плагин автоматически построит дерево файлов на основе подпапок. Путь к выбранной папке и содержимое библиотеки кэшируются между сессиями с помощью `figma.clientStorage`, поэтому вам не придется выбирать папку заново при каждом запуске.

### Файлы и цепочки

- **Shader Library** — кнопка **Choose Shader Library...** открывает диалог выбора папки. Все поддерживаемые файлы шейдеров и цепочек внутри нее появятся в разделе **User Library**.
- **Load Shader** — загрузка одиночного шейдера из файла `.sfshader`.
- **Save Shader** — сохранение активного шейдера, включая его код, параметры и маски, в JSON-файл `.sfshader`.
- **Load Chain** — загрузка полной цепочки слоев, включая слои, маски, Master Mask и настройки рендера, из JSON-файла `.sfchain`.
- **Save Chain** — сохранение текущей цепочки слоев в JSON-файл `.sfchain`.
- **Export Shader** — экспорт исходного кода и конфигурации активного шейдера в файл `.sfshader`.

### Форматы экспорта

#### `.sfshader`

JSON-файл, содержащий:

- Исходный код GLSL.
- Значения `uniform`-переменных и настройки параметров.
- Маски слоя.
- Метаданные шейдера.

#### `.sfchain`

JSON-файл, содержащий:

- Полный стек слоев.
- Слои-генераторы и слои-эффекты.
- Маски отдельных слоев.
- Глобальную маску Master Mask.
- Порядок слоев и настройки смешивания.
- Настройки рендера.

## 4. Маски — редактор стека масок

<img width="1174" height="850" alt="Снимок экрана 2026-08-18 120807" src="https://github.com/user-attachments/assets/a381c22c-7745-4aa9-8447-170f6d754672" />

> Маски определяют область слоя, в которой виден эффект. Они полезны для локального применения шейдеров — например, для размытия только одного угла или добавления свечения в центре изображения.

### Как работают маски

Каждый слой шейдера может иметь собственный стек масок. Маска представляет собой карту в градациях серого:

- Белые области показывают слой.
- Черные области скрывают слой.
- Серые области частично проявляют слой.

Несколько масок на одном слое комбинируются суммарно, то есть аддитивно. Итоговый результат слоя рассчитывается по принципу:

```text
result = mix(underlying layer, current layer, coverage)
```

Маска **Master Mask** применяется после того, как все слои были скомпонованы, и управляет видимостью итогового результата.

### Как открыть

1. Во вкладке **Shader** добавьте слой **Generate** или **Effect**.
2. Нажмите на иконку маски справа от названия слоя.
3. Откроется модальное окно **Mask Stack Editor**.
4. Чтобы отредактировать итоговую композицию, используйте кнопку **Master Mask** на нижней панели.

### Типы масок

| Тип | Описание |
|:---|:---|
| **Circle / Ellipse** | Круг или эллипс с настраиваемым радиусом и масштабом |
| **Rectangle / Rounded Rect / Square** | Прямоугольник с опциональным закруглением углов |
| **Polygon / Star** | Многоугольник или звезда с настраиваемым количеством вершин |
| **Line** | Линия с настраиваемой толщиной |
| **Procedural Noise** | Процедурные маски шума: FBM, Cellular, Ridged, Turbulence, Billow и Value |
| **Free Form Bezier** | Редактор векторных кривых с угловыми и сглаженными опорными точками и направляющими Безье |
| **Fragment Shader** | Полностью настраиваемая GLSL-маска. Белые значения альфа-канала обозначают видимые области |

### Редактор Free Form Bezier

**Free Form Bezier** — это полноценный редактор векторных кривых, разработанный по аналогии с инструментами из Illustrator и Figma.

- Желтые квадраты — угловые точки (**Corner anchors**).
- Оранжевые круги — сглаженные точки (**Smooth anchors**) с симметричными направляющими.
- Зеленые и синие линии — направляющие Безье, управляющие направлением и изгибом кривой.
- Нажмите на сегмент кривой, чтобы добавить новую точку.
- Дважды нажмите на опорную точку, чтобы переключить ее тип между **Smooth** и **Corner**.
- `Alt` + двойной клик по опорной точке — удалить точку.
- `Alt` + перетаскивание направляющей — сделать направляющие независимыми.
- `Ctrl/Cmd` + клик по направляющей — сбросить направляющую.
- Нажмите правой кнопкой мыши на опорную точку, чтобы удалить ее.

### Общие параметры

- **Enable** — включить или выключить маску.
- **Invert** — инвертировать маску.
- **Strength** — общая сила маски от `0..1`.
- **Feather** — смягчение краев маски. `0` — острый край; `1` — максимально мягкий переход.
- **Edge Uneven** — добавляет неровность краю на основе шума:
  - **Soft** — плавные неровности на основе FBM.
  - **Sharp** — рваные, зубчатые края.
- **Rotation** — поворот маски.
- **Position** — перемещение маски.
- **Scale** — изменение размера маски.

### Визуальное редактирование

В правой части **Mask Stack Editor** находится интерактивная область предпросмотра, наложенная на изображение:

- Зажмите ЛКМ внутри фигуры и перетаскивайте ее для перемещения.
- Потяните за один из восьми белых маркеров ограничительной рамки, чтобы изменить масштаб.
- Потяните за круглый маркер над верхней гранью, чтобы повернуть фигуру.
- Дважды нажмите на название маски, чтобы переименовать ее прямо в списке.
- Нажмите `Enter` для подтверждения нового имени.
- Нажмите `Escape` для отмены переименования.

Для масок **Free Form Bezier**:

- Нажмите на сегмент, чтобы вставить новую опорную точку.
- Перетаскивайте точку для ее перемещения.
- Дважды нажмите на точку, чтобы изменить ее тип.
- Используйте сочетания клавиш с модификаторами для удаления точек и настройки симметрии направляющих.
- Перетаскивайте направляющие Безье для управления изгибом каждого сегмента.

### Пример работы

1. Добавьте слой **Gaussian Blur**.
2. Откройте стек масок этого слоя и добавьте маску **Circle**.
3. Установите **Feather** на `0.05`, чтобы получить мягкий, но четкий край.
4. Включите **Edge Uneven** на уровне `0.3` в режиме **Soft**.
5. Переместите круг в нужную область изображения.
6. Закройте редактор. Теперь размытие применяется только внутри круга.

Чтобы применить виньетку ко всей композиции:

1. Нажмите **Master Mask** на нижней панели.
2. Добавьте маску **Ellipse** или кастомную маску **Free Form Bezier**.
3. Инвертируйте маску или настройте ее размытие (**Feather**).
4. Примените результат к холсту.

## 💡 Полезные советы

- **Умные диапазоны параметров:** используйте понятные имена `uniform`-переменных, такие как `uAngle`, `uSpeed`, `uOpacity` или `uOffset`, чтобы автоматически получать подходящие диапазоны ползунков.
- **Пользовательские диапазоны:** переопределяйте автоматические диапазоны с помощью комментариев прямо в коде:

  ```glsl
  uniform float uAngle; // @range -45 45
  ```

- **Палитра выбора цвета:** добавляйте `Color`, `color`, `Col` или `col` в имена переменных типа `vec3`:

  ```glsl
  uniform vec3 uGlowColor;
  ```

- **Master Mask:** используйте ее для создания виньеток, оформления рамок, финального кадрирования или эффектов, которые должны затрагивать всю скомпонованную композицию.
- **Маски слоев:** комбинируйте несколько масок на одном слое для создания сложных областей воздействия.
- **Маски Безье:** используйте угловые точки (**Corner**) для геометрических форм и сглаженные точки (**Smooth**) для плавных органических кривых.
- **Работа с библиотекой:** дважды нажмите на шейдер для быстрого добавления; используйте контекстное меню, если нужно загрузить готовую цепочку `.sfchain`.
- **Компоновка предпросмотра:** перетаскивайте разделитель между редактором и окном предпросмотра, чтобы выделить больше места под код или визуальный результат.
- **Производительность:** ресурсоемкие эффекты, такие как blur и bloom, обычно проще контролировать и оптимизировать в виде отдельных слоев, а не одного большого шейдера.
- **Exact Preview:** включайте этот режим, если вам важна попиксельная точность и максимальное соответствие финальному рендеру в Figma.
- **Качество экспорта:** выбирайте **Image Origin**, чтобы сохранить исходное разрешение загруженного изображения, или **8192** для получения Ultra-HD-рендера.
