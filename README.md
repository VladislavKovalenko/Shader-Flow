# Shader Flow — Figma Plugin

Плагин для создания и применения GLSL-шейдеров прямо в Figma. Генерируйте текстуры с нуля, обрабатывайте изображения цепочкой эффектов, рисуйте маски и экспортируйте результат обратно на холст.

---

## Возможности

| | |
|:---|:---|
| 🎨 **Живое превью** | Реалтайм-рендер шейдера с мгновенным обновлением при изменении параметров |
| 📝 **GLSL-редактор** | Редактор кода с нумерацией строк, мгновенной компиляцией и подсветкой ошибок |
| 🎛 **Параметры** | Слайдеры, цветовые пикеры и переключатели, автоматически создаваемые из `uniform` |
| 🥞 **Слои** | Многослойный стек: генераторы + эффекты, drag & drop, blending |
| 🎭 **Маски** | Визуальный редактор масок: примитивы, произвольные кривые, процедурный шум, кастомный GLSL |
| 📚 **Библиотека** | Встроенные пресеты + импорт пользовательской библиотеки из папки |
| 💾 **Цепочки** | Сохранение и загрузка цепочек слоёв (`.sfchain`) |
| 📤 **Экспорт** | Экспорт исходного GLSL-кода (`.txt`) и рендер на холст |
| ↩️ **Undo / Redo** | Полная поддержка отмены и повтора действий |
| 🔍 **Точный рендер** | Pixel-perfect превью с разрешением до **4096×4096** |
| 🎬 **Анимация** | Счётчик FPS и ограничение частоты кадров |
| 🔎 **Масштаб UI** | Масштаб интерфейса от 100% до 250% |

### Для чего подходит

- Процедурные текстуры и шумы
- Glitch-эффекты и искажения
- Размытие и резкость
- Цветокоррекция и тонирование
- Стилизация под ручную роспись
- Анимированные процедурные шейдеры

## Установка

> Для установки плагина разработчика понадобится **десктопное приложение Figma**.

1. Кликните правой кнопкой мыши по холсту.
2. Выберите **Plugins → Development → Import plugin from manifest**.
3. В открывшемся окне проводника перейдите в папку с исходным кодом плагина и выберите файл `manifest.json`.
4. Запустите плагин: он появится в списке **Plugins → Development → Shader Flow**. Нажмите на него для запуска.

---

## 🚀 Быстрый старт

1. Запустите **Shader Flow**.
2. Выделите **Frame** на холсте (пропустите, если работаете с отдельным изображением).
3. Выделите **слой с изображением** внутри фрейма.
4. Перейдите во вкладку **Library**.
5. Кликните правой кнопкой по эффекту (например, **Chromatic Aberration**) → **Add as new layer**.
6. Перейдите во вкладку **Shader** и настройте параметры добавленного шейдера.
7. Примените результат:
   - **Add on top** — добавляет новое изображение поверх существующих заливок.
   - **Replace** — заменяет текущую заливку изображения у выделенного слоя.

## 1. Вкладка Shader — Редактор и Превью

<img width="800" height="580" alt="Shader" src="https://github.com/user-attachments/assets/8b28cd98-a04f-4be1-84f1-1b68ea42d202" />

> Основная рабочая область. Здесь вы пишете код, настраиваете параметры и видите результат в реальном времени.

### Пошагово:

1. **Выберите слой** в Figma.  
   Если на слое есть изображение — плагин автоматически подхватит его как текстуру для шейдера.

2. **Parameters** (левая панель).  
   Плагин сам находит все `uniform` переменные в вашем GLSL-коде и создаёт удобные элементы управления:
   - `float` / `int` — слайдеры с регулируемым диапазоном
   - `vec3` — цветовые палитры с HEX-вводом и попап-пикером
   - `bool` — переключатели
   - `vec2` / `vec3` — числовые поля
   - Меняйте значения — превью обновляется мгновенно.

3. **Shader Layers** (коллапс-панель слева).  
   Система слоёв для наложения эффектов цепочкой:
   - Нажмите `+`, чтобы добавить слой.
   - **Generate** — слои, которые создают картинку с нуля (градиенты, шум, огонь).
   - **Effect** — слои, которые обрабатывают результат предыдущего слоя (блюр, хроматическая аберрация, bloom).
   - Меняйте порядок слоёв перетаскиванием (drag & drop).
   - У каждого слоя есть иконка маски — нажмите её, чтобы открыть **Mask Stack Editor**.

4. **Code Editor** (центр).  
   Редактор GLSL-кода с нумерацией строк. Пишите свой код или редактируйте загруженный пресет.  
   Встроенные переменные (доступны без объявления):
   - `iResolution` — размер canvas
   - `iTime` — время анимации в секундах
   - `iMouse` — позиция курсора (0..1)
   - `uTexture` / `uHasTexture` — входная текстура (для эффектов)

5. **Preview** (правая панель).  
   Живое WebGL-превью с прозрачным фоном (шашечки). Кнопки управления:
   - `⏸` — Play / Pause анимации
   - `↺` — сбросить время в ноль
   - `⇅` / `⇆` — отразить превью по вертикали / горизонтали (только для просмотра, не влияет на экспорт)

6. **Mask Stack Editor** (модальное окно).  
   Каждый слой можно обрезать маской:
   - **Primitives**: Circle, Ellipse, Rectangle, Rounded Rect, Square, Polygon, Star, Line
   - **Procedural**: Noise (FBM, Cellular, Ridged, Turbulence, Billow, Value)
   - **Custom**: Free Form Curve — рисуйте произвольные формы точками, сглаживайте кривые (Catmull-Rom), меняйте кривизну сегментов ПКМ-перетаскиванием
   - **Code**: собственный фрагментный шейдер для маски
   - Настройки: Invert, Strength, Feather, Edge Uneven (неровности края), Rotation, Position, Scale

7. **Экспорт на холст** (нижняя панель).  
   - **Replace** — заменяет содержимое выделенного слоя результатом рендера.
   - **Add on top** — создаёт новое изображение поверх выделенного слоя.
   - **Code** — показать / скрыть редактор кода (если нужен только превью и параметры).

## 2. Вкладка Library — Библиотека шейдеров

<img width="800" height="580" alt="Library" src="https://github.com/user-attachments/assets/4372329c-342b-46ca-8909-91d916500754" />

> Хранилище готовых шейдеров. Быстрая загрузка пресетов в редактор.

### Что здесь:

- **Basic Library** — встроенные пресеты, идущие с плагином:
  - 🌊 **Noise Field** — процедурный шум с настраиваемыми цветами
  - 🌈 **Gradient Waves** — анимированные волны-линии
  - 🔥 **Fire** — процедурный огонь через FBM-шум
  - 🟣 **Plasma** — классический плазменный эффект
  - 🌌 **Chromatic Aberration** — цветовые сдвиги по краям
  - 💧 **Glass / Ripple** — эффект стекла / ряби
  - 🌫 **Gaussian Blur** — размытие по Гауссу
  - ✨ **Bloom** — свечение ярких участков
  - ✏️ **Custom Generate** — шаблон для создания своего генератора с нуля
  - ✏️ **Custom Effect** — шаблон для создания своего эффекта-обработчика

- **User Library** — ваши собственные шейдеры.  
  Чтобы они появились здесь, выберите папку с `.txt` файлами во вкладке **Settings** → *Shader Library*.  
  Плагин автоматически построит дерево файлов по подпапкам.

### Как пользоваться:

1. Кликните на пресет в библиотеке — он загрузится в редактор.
2. Если это эффект — убедитесь, что у вас выбран слой с изображением (или уже есть генератор ниже по цепочке).
3. Редактируйте параметры и применяйте результат на холст.

## 3. Вкладка Settings — Настройки и экспорт

<img width="800" height="580" alt="Settings" src="https://github.com/user-attachments/assets/50b401a5-77ad-41a5-9b15-4b06a8227c81" />

> Тонкая настройка рендера, интерфейса и работы с файлами.

### Параметры:

| Настройка | Описание |
|-----------|----------|
| **Exact Preview** | Когда включено, превью максимально точно соответствует финальному изображению, которое попадёт в Figma. |
| **Show FPS** | Показывает счётчик кадров в углу превью. |
| **FPS Color** | Цвет счётчика: Black или White. |
| **Frame Rate** | Ограничение FPS анимации: 60 / 30 / 120 / Uncapped (без ограничения). |
| **UI Scale** | Масштаб всего интерфейса плагина от 100% до 250%. Значение сохраняется между запусками. |
| **Render Size** | Размер итоговой картинки при экспорте:<br>• *Preview size* — как в окне превью<br>• *512/1024/2048/4096* — фиксированный квадрат<br>• *Node size* — по размеру выделенного слоя в Figma |

### Файлы и цепочки:

- **Shader Library** — кнопка *Choose Shader Library...* открывает диалог выбора папки. Все `.txt` файлы из неё появятся в **User Library** (вкладка Library).
- **Load Chain** — загрузить ранее сохранённую цепочку слоёв (все эффекты, маски и параметры) из файла.
- **Save Chain** — сохранить текущую цепочку слоёв в файл (удобно для переноса между проектами).
- **Export Shader** — скопировать исходный GLSL-код текущего активного шейдера.

## 4. Маски — Mask Stack Editor

<img width="800" height="580" alt="Mask" src="https://github.com/user-attachments/assets/d2ba9a83-4b82-412c-a6a0-37807813c70d" />

> Маски определяют, в какой области слоя будет виден эффект. Это мощный инструмент для локального применения шейдеров — например, размыть только угол или добавить свечение только в центре.

### Как работают маски

Каждый слой в стеке может иметь собственный **стек масок**. Маска — это grayscale-карта: белые области показывают слой, чёрные — скрывают. Несколько масок на одном слое складываются аддитивно: чем больше масок, тем шире зона действия слоя.

Итоговая формула:  
`result = mix(нижележащий слой, текущий слой, coverage)`

### Как открыть

1. Во вкладке **Shader** добавьте любой слой (Generate или Effect).
2. В списке слоёв нажмите иконку **маски** (кнопка справа от имени слоя).
3. Откроется модальное окно **Mask Stack Editor**.

### Типы масок

| Тип | Описание |
|-----|----------|
| **Circle / Ellipse** | Окружность или эллипс с настраиваемым радиусом |
| **Rectangle / Rounded Rect / Square** | Прямоугольник со скруглёнными углами |
| **Polygon / Star** | Многоугольник или звезда с регулируемым количеством вершин |
| **Line** | Линия заданной толщины |
| **Procedural Noise** | Процедурный шум (FBM, Cellular, Ridged, Turbulence, Billow, Value) как маска — идеально для органических краёв |
| **Free Form Curve** | Произвольная замкнутая фигура. Кликайте на превью, чтобы добавлять точки, перетаскивайте жёлтые узлы, двойной клик — удалить точку. ПКМ-перетаскивание сегмента — меняет кривизну (Catmull-Rom). Включите **Smooth (Curves)**, чтобы все сегменты были изогнутыми. |
| **Fragment Shader** | Полностью кастомная маска на GLSL. Пишите свой код, где белый цвет в alpha-канале = видимая область. |

### Общие параметры

- **Enable** — включить / выключить маску.
- **Invert** — инвертировать маску (чёрное ↔ белое).
- **Strength** — глобальная непрозрачность маски (0..1). Позволяет делать частичное затухание.
- **Feather** — размытие края маски. 0 = резкий край, 1 = максимально мягкий переход.
- **Edge Uneven** — добавляет "неровности" краю фигуры (шум). Полезно для имитации рваной бумаги, краски или органических краёв.
  - *Soft* — плавные неровности через FBM-шум.
  - *Sharp* — острые, зазубренные края.

### Визуальное редактирование

В правой части **Mask Stack Editor** находится интерактивное превью поверх вашего изображения:

- **Перемещение** — зажмите ЛКМ внутри фигуры и тащите.
- **Масштабирование** — потяните за 8 белых ручек на Bounding Box.
- **Вращение** — потяните за круглую ручку над верхней границей.
- **Free Form**:
  - ЛКМ на пустом месте рядом с сегментом — вставляет новую точку между ближайшими.
  - Перетаскивание жёлтой точки — двигает вершину.
  - Двойной клик по точке — удаляет её.
  - ПКМ + перетаскивание вверх/вниз на сегменте — меняет кривизну (tension).

### Пример workflow

1. Добавьте слой **Gaussian Blur**.
2. Откройте **Mask Stack** и добавьте маску **Circle**.
3. Уменьшите **Feather** до `0.05`, чтобы край был мягким, но не размытым.
4. Включите **Edge Uneven** на `0.3` (Soft) — край круга станет слегка "рваным", как акварель.
5. Перетащите круг в превью на нужную область изображения.
6. Закройте редактор. Теперь блюр применяется только внутри круга.

## 💡 Советы

- **Параметры из кода**: просто напишите `uniform float uMyValue;` в шейдере — слайдер появится в панели Parameters автоматически.
- **Цвета**: для получения color-picker'а назовите `vec3` переменную с суффиксом `Color` / `Col` / `color` / `col`, например: `uniform vec3 uGlowColor;`
- **Маски**: можно комбинировать несколько масок на одном слое. Они суммируются аддитивно.
- **Производительность**: тяжёлые эффекты (блюр, bloom) лучше делать отдельными слоями, а не писать один гигантский шейдер.
